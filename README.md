# Mitsuki Web

Official website for **Mitsuki** — **身につく日本語**.

Mitsuki is a Japanese learning app focused on two essentials: a fast offline dictionary and beautiful flashcards you can review anywhere.

## About Mitsuki

Mitsuki helps Japanese learners move from lookup to memory:

- Search Japanese words instantly with an offline dictionary
- Save useful words as clean flashcards
- Review cards across Mac and iPhone
- Use extra study tools such as JLPT practice, AI explanations, business Japanese drills, widgets, subtitle capture, and voice review

The main focus of Mitsuki is intentionally simple:

> Dictionary + Flashcards.

Everything else is an extra.
